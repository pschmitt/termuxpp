TermuxPP:Boot

Run your chosen programs automatically when Android starts.

Set up boot scripts

  • Open TermuxPP:Boot once after installation. Android must launch the app before it delivers boot broadcasts.
  • Put scripts in ~/.config/termuxpp/boot/.
  • For each filename, the first regular file found is used in this order: ~/.config/termuxpp/boot/, ~/.config/termux/boot/, then ~/.termux/boot/.
  • Scripts with different filenames from all three directories are retained; same-named lower-priority scripts are skipped.
  • Scripts run in filename-sorted order.
  • Consider running termux-wake-lock first if the device should stay awake.

Example script

Create ~/.config/termuxpp/boot/start-sshd containing:

#!/data/data/dev.pschmitt.termux/files/usr/bin/sh
termux-wake-lock
sshd
