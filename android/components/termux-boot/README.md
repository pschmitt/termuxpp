# TermuxPP Boot integration

This directory contains the Boot component built into the main TermuxPP
APK. See [Boot, Float, Styling, and Widget](../docs/en/integrations.md#boot-float-styling-and-widget) for setup and
[Android builds](../AGENTS.md) for contributor instructions.

The component is based on [Termux Boot](https://github.com/termux/termux-boot).
