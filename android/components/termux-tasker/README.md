# TermuxPP Tasker integration

This directory contains the Tasker component built into the main TermuxPP
APK. See [Tasker and Locale](../docs/en/integrations.md#tasker-and-locale) for setup and
[Android builds](../AGENTS.md) for contributor instructions.

The component is based on [Termux Tasker](https://github.com/termux/termux-tasker).
