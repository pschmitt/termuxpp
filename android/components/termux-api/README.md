# TermuxPP API integration

This directory contains the API component built into the main TermuxPP
APK. See [API](../docs/en/integrations.md#api) for setup and
[Android builds](../AGENTS.md) for contributor instructions.

The component is based on [Termux API](https://github.com/termux/termux-api).

Shell commands use the [TermuxPP API helper package](../termux-api-package/TERMUXPP.md).
