# TermuxPP Widget integration

This directory contains the Widget component built into the main TermuxPP
APK. See [Boot, Styling, and Widget](../../../docs/en/integrations.md#boot-styling-and-widget) for setup and
[Android builds](../AGENTS.md) for contributor instructions.

The component is based on [Termux Widget](https://github.com/termux/termux-widget).
